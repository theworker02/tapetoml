# tapetoml

Tape identifiers and toml tokens for idempotent workflows.

**Site:** https://theworker02.github.io/tapetoml/

## Install / run

```bash
git clone https://github.com/theworker02/tapetoml.git
cd tapetoml
node src/cli.js
node --test
```
